Accessibility Statement

At CyJimm, we work to make the website as convenient as possible for people with a range of needs and ways of using the web. We continue to improve accessibility while preserving the website's content and operation.

Accessibility Features on the Website

  • A skip link to the main content on every public page.
  • Visible keyboard focus and keyboard-operable controls.
  • Semantic structure, headings, form labels, and image alternative text that were reviewed and improved where needed.
  • Support for right-to-left Hebrew and left-to-right English.
  • Support for the system preference to reduce motion.

Accessibility Controls

The floating accessibility button can increase or decrease text size and enable high contrast, grayscale, highlighted links, a readable font, and the stopping of non-essential animations. The controls can also be reset. Settings are stored in the browser and persist between pages.

Keyboard Use

You can navigate the website with Tab and Shift+Tab and activate links and buttons with Enter or Space. When the accessibility panel is open, Escape closes it and returns focus to the accessibility button.

Known Limitations

Some older content or interactive pages may still not provide an optimal experience with every combination of browser and assistive technology. We continue to review and improve the website and do not claim complete accessibility or official certification.

Reporting an Accessibility Problem

If you encounter difficulty using the website, contact us through the existing contact address: hello@cyjimm.com. Please include the page, the action you attempted, and the browser or assistive technology you used.
