Endpoints at scale

Security and response

Deployment and configuration of EDR, antivirus, and endpoint protection; email filtering and configuration hardening. Experience with alert triage, IOC blocking, SOC coordination, Splunk, and Wazuh.

Remote access

Deploying and supporting Harmony and FortiClient, including traveling users and mobile devices.

Automation

PowerShell for permissions, groups, maintenance, and health checks. Python, Power Automate, and Google Apps Script where they fit.

AI tools

Documentation and RCA

Root cause analysis, runbooks, and handling summaries, so the next occurrence is shorter.

Web and Cloudflare

Static sites, Cloudflare Workers, Turnstile, CSP, and security headers. This site is built that way.
