מי אנחנו

CyJimm מובילה פרויקטי אבטחה ותשתיות לארגונים שרוצים להיות ממוקדים תוצאה. אנחנו משלבים ניסיון Hands-On, אוטומציה חכמה, ומתודולוגיה של "Secure by Default".

CyJimm הוקמה ומובלת על ידי מתן ג'מיל.

Windows Server / AD / GPOCloudflare / Zero-TrustLinux • Kali • WazuhAzure / M365 / ExchangeCI/CD • GitHub Actions

הצעת ערך

אנחנו לא מוכרים שקופיות. אנחנו בונים מערכות: סטנדרטיזציה, הקשחות, ניטור, ותהליכי תגובה - עם דוקומנטציה מסודרת והעברה מסודרת לצוות הלקוח.

  • בפרויקטים בהיקף מוגדר ניתן לעיתים להשלים Security Baseline בתוך מספר שבועות, בהתאם לסביבה ולתכולה.
  • Runbooks ו-Playbooks בעברית/אנגלית.
  • תמחור שקוף לפי תכולה, לא לפי "רשיון קסם".
