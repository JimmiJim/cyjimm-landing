מי עומד מאחורי CyJimm

CyJimm היא פרקטיקה לתשתיות Windows ו-Linux, אבטחה ארגונית ואוטומציה. העבודה כוללת הגדרת סטנדרטים, בניית תהליכים ושיפור היציבות והאבטחה בסביבה הקיימת.

העבודה ב-CyJimm מובלת ומבוצעת ישירות על ידי מתן ג'מיל.

עובד עם תשתיות IT, אבטחה ואוטומציה, בדגש על סטנדרטיזציה, יציבות והקשחה. בין הפרויקטים: ערכת התקנות מותאמת ל-Windows 11 ול-Kali, מערכות התרעה מבוססות SLA וניהול סביבות AD/GPO מורכבות ללא Intune.

מערכות ליבה

  • Windows Server (AD, DNS, DHCP, GPO), pfSense, VLANs
  • Linux: Kali, Parrot, Elementary - PrivEsc, Hardening
  • Automation: PowerShell 7+, Python 3.12, GitHub Actions
  • SIEM/Monitoring: Splunk, Wazuh, Grafana Integration

עבודות נבחרות

סטנדרטיזציה ואוטומציה של משימות תמיכה חוזרות באמצעות PowerShell.

בניית ערכת התקנות אחידה לתחנות עבודה ולסביבת המעבדה.

בניית Dashboards ב-Splunk וב-Wazuh לצורך נראות תשתית ואבטחה.
